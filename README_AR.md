# JOYROOM Bluetooth Explorer (Android Studio)

مشروع أندرويد أولي بلغة Java لفحص Bluetooth LE وGATT على Android 6+، مع استهداف Android 14 (API 34).

## ما يفعله
- يطلب أذونات Bluetooth المناسبة لإصدار أندرويد.
- يمسح أجهزة BLE ويعرض الاسم، عنوان الجهاز الذي يكشفه النظام، RSSI، الخدمات المعلنة، بيانات الشركة وService Data والبايتات الخام للإعلان إن وفّرها النظام.
- يتيح الاتصال بجهاز من القائمة واكتشاف خدمات GATT وخصائصها ووصفاتها وصلاحياتها، ثم يحاول قراءة الخصائص التي تعلن عن READ بالتتابع ويسجل النتيجة أو الرفض.
- يجمع سجلًا ويصدره كملف JSON.

## ما لا يضمنه
- لا يمكنه إجبار الساعة على البث أو كشف MAC الحقيقي إذا كان النظام يعرض عنوانًا عشوائيًا/خاصًا.
- لا يكسر الاقتران أو التشفير ولا يرسل أوامر كتابة تلقائية. الخصائص التي تحتاج مصادقة قد ترفض القراءة أو الكتابة.
- لا يلتقط حركة تطبيق SMART-TIME PRO من تطبيق آخر، ولا يجرب الكتابة أو الأوامر الخاصة تلقائيًا؛ هو أداة تشخيص آمنة أولية.

## البناء
1. افتح Android Studio حديثًا.
2. اختر Open ثم مجلد `JOYROOM_Bluetooth_Explorer`.
3. اسمح له بتنزيل Gradle/Android SDK إذا طلب ذلك (يتطلب إنترنت أثناء الإعداد).
4. من Build اختر Build APK(s).
5. الملف الناتج عادةً: `app/build/outputs/apk/debug/app-debug.apk`.

## الاستخدام
1. ثبّت APK وامنحه Nearby devices.
2. أوقف مؤقتًا اتصال الساعة بتطبيق SMART-TIME PRO إن كان يحتجز الاتصال.
3. اضغط بدء المسح، ثم اضغط جهاز الساعة للاتصال.
4. انتظر ظهور خدمات GATT في السجل.
5. اضغط تصدير التقرير واحفظ JSON وشاركه للتحليل.

إذا لم يظهر أي جهاز: تحقق من تشغيل Bluetooth، ومنح الأذونات، وإيقاف أي مسح آخر، وجرّب بعد إعادة تشغيل Bluetooth. أندرويد قد لا يعرض MAC المصنع الحقيقي.
